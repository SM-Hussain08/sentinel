# SENTINEL

**AI-Powered Anomaly Detection & Incident Intelligence Platform**

SENTINEL is a final-year Computer Science portfolio project that simulates a corporate IT environment, generates synthetic security events, detects anomalous behavior using machine learning, correlates suspicious activity into incidents, and presents security intelligence through a modern web dashboard.

## Project Goals

SENTINEL demonstrates practical use of:

* Artificial Intelligence
* Machine Learning
* Data Science
* Synthetic Data Generation
* Data Engineering
* Backend Development
* Frontend Development
* PostgreSQL
* Real-Time Systems
* Docker
* Linux / Ubuntu Development
* Software Engineering Best Practices
